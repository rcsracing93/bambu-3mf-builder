# Generated aliases

Generated by `tests/gen_aliases.py` from the option labels in Bambu Studio's source (2.8.2.61, 2.9.1.70, 2.9.2.62). Do not edit by hand.

A label alias is the label Studio shows, lowercased, with every run of other characters turned into `_`. It is only a second spelling of the real key. Setting an alias and its real key together is an error. The short names in [job-format.md](job-format.md) come first and win over these. An alias valid in one Studio version only works only for that version.
